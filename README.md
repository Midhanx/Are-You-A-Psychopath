# 🧠 Are You a Psychopath?

An interactive 15-question personality quiz exploring psychopathy-like traits through hypothetical situations.

Built with **HTML, CSS, and vanilla JavaScript**.

## ✨ Features

* 15-question interactive quiz
* Automatic progression after selecting an answer
* Previous-question navigation
* Progress indicator
* Dark minimal UI with red accents
* Animated results
* Responsive design
* Lightweight and fast

## 🌐 Live Website

The official version of the quiz is available on the hosted website.

## ⚠️ Disclaimer

This quiz is created for entertainment purposes only.

It is not a clinical psychological assessment and cannot diagnose psychopathy, antisocial personality disorder, or any other mental-health condition.
